Lecture 4

Types of Technical Paper

Introduction

Technical writing produces many types of documents. Our lecture distinguishes between technical reports, proposals, abstracts, and other structured papers. Each type has a specific purpose, audience, and format.

What Is a Technical Report?

Key Definition

A technical report is a specific type of technical writing used to convey data, research, or findings in a structured, objective, and detailed way to a specific audience.

Part 1: The General Report Structure

  • Title Page — Contains the title, author's name, date, and organization's name.
  • Table of Contents — Lists sections and sub-sections with page numbers.
  • Abstract — Provides background, states the purpose, and outlines the scope.
  • Body — The main part, containing data, analysis, and results.
  • Summary — Summarizes key findings and outcomes.
  • Recommendations — Suggests a course of action based on findings.

Part 2: Two Main Categories of Reports

1. Informal Reports

Short reports designed for circulation only within an organization.

  • Memorandum Report — Internal business document
  • Letter Report — External communication in business letter format
  • Bulletins — Brief announcements or updates
  • Booklets — Small informational publications
  • Abstract — Short summary of a larger work

2. Formal Reports

Structured, comprehensive documents that include formal elements like transmittal letters, executive summaries, and detailed sections.

Part 3: Memorandum Report

Header

  • TO: Recipient's name and title
  • FROM: Sender's name and title
  • DATE: Date the memo is written
  • SUBJECT: Concise, clear summary of the memo's topic

Part 4: Letter Report

A technical report written in the format of a business letter, used for external communication.

Part 5: Abstract

  • Descriptive Abstract — States what the document contains.
  • Informative Abstract — Summarizes the document's content including purpose, methods, results, and conclusion.

Part 6: Proposal

A persuasive document that outlines a plan or project and convinces a specific audience to approve it.

  • Introduction — Hook the reader and state the problem and solution.
  • Problem Statement — Define the issue or need.
  • Proposed Solution — Describe the plan.
  • Methodology — Steps to implement the solution.
  • Timeline — Schedule for the project.
  • Budget — Breakdown of costs.
  • Conclusion — Final, persuasive summary.

Part 7: Basic Techniques in Technical Writing

1. Definition

  • Informal — a word or phrase (synonym). Example: compensation = pay
  • Formal — a sentence with species, genus, and differentia.
  • Amplified — additional sentences that expand a formal definition.

2. Classification

The arrangement of objects, people, or ideas with shared characteristics into classes or groups.

3. Partition

An analysis that divides a singular item into parts, steps, or aspects.

SubjectClassification (Group)Partition (Parts)
CakeButter, chiffon, angel, fruitEgg, butter, flour, sugar, milk
LetterApplication, business, inquiry, orderHeading, date line, salutation, body
TreesAngiosperms, gymnospermsCrown, leaves, twigs, trunk, roots

4. Description of a Process

Description of an action, organized as: Introduction → Step-by-step description → Conclusion.

5. Description of a Mechanism

Explains a device's physical components, its function, and how those components relate.

Self-Check

1. What are the two main categories of technical reports?

Informal reports and Formal reports.

2. Name four parts of a formal report.

Transmittal letter, title page, abstract, table of contents, body, conclusions, recommendations, bibliography.

3. What are the four header fields of a memorandum report?

TO, FROM, DATE, SUBJECT.
